# Development

Run these commands from `projects/internals/patterns` with `mise exec --`.

| Command                | Description                            |
| ---------------------- | -------------------------------------- |
| `pnpm run build`       | Build the library and example metadata |
| `pnpm run build:watch` | Build with file watching               |
| `pnpm run dev`         | Start the development server           |
| `pnpm run lint`        | Lint source files                      |
| `pnpm run test:types`  | Type-check source and examples         |
| `pnpm run ci`          | Run build, lint, and type checks       |
