# Internals

The internals directory is the home for all common tooling, build scripts, and configuration for published packages. These internals do not publish as standalone packages.

| Project | Purpose |
| --- | --- |
| [`ci`](./ci/) | CI validation, cache checks, coverage, metrics, and notice reporting. |
| [`design`](./design/) | Build-time design analysis and the generated design guidance artifact. |
| [`eslint`](./eslint/) | Shared ESLint configurations and custom repository rules. |
| [`metadata`](./metadata/) | Metadata generation, indexes, and services for packages, APIs, examples, tests, and releases. |
| [`patterns`](./patterns/) | Reusable HTML application-pattern examples. |
| [`testing`](./testing/) | Web-component test fixtures, interaction helpers, lifecycle utilities, and axe support. |
| [`tools`](./tools/) | Shared services for the CLI, site, starters, playgrounds, and agent tooling. |
| [`vite`](./vite/) | Shared Vite build and Vitest configurations, plugins, runners, and setup. |
