# List

The Typography utilities provides a flexible API to apply typography styles explicitly to list elements. This enables full control of the visual styling of an element separate from the HTML semantics.

## Installation

```shell
npm install @nvidia-elements/themes @nvidia-elements/styles
```

```css
/* import the global CSS into your project (import may vary based on build tools) */
@import '@nvidia-elements/styles/dist/typography.css';
```
